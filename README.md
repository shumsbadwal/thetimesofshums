# The Times of Shums

A daily, desk-by-desk independent news reader with dated archives, published on GitHub Pages.

The newspaper is prepared in ChatGPT and committed to this repository via the connected GitHub integration. No OpenAI API key or daily GitHub Actions research workflow is required.

**Hosting:** Repository Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/(root)` → Save. The current `index.html` serves the homepage; each dated edition is kept in its own folder. New editions require successful GitHub commits and are not guaranteed by scheduling alone.

**Editorial note:** Previously compiled 18 November 2026 edition material is retained as an archive and has not been independently re-audited in full. Follow individual original source links for full reporting. The site should not imply that source links alone verify every claim.

**Privacy:** GitHub Pages from a public repository is publicly accessible.
